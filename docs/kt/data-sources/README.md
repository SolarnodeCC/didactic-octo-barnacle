# Data sources

The platform uses three academic sources. CI never calls them; tests use recorded fixtures (see [test data](../test/test-data.md)).

- [OpenAlex](openalex.md): publications, authors, institutions, and citations.
- [arXiv](arxiv.md): preprints in AI, software engineering, and computer science.
- [Semantic Scholar](semantic-scholar.md): paper metadata, citation graphs, and recommendations.
