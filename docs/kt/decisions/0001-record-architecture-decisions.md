# 0001: Record architecture decisions

- Decision status: Accepted
- Date: 2026-10-28

## Context

Decisions made in chat, meetings, or pull request threads are hard to find later, and new contributors and agents cannot see why the platform is built the way it is.

## Decision

Record every significant architecture, technology, or process decision as an ADR in `docs/kt/decisions/`, one decision per file.

## Consequences

Contributors and reviewers can trace decisions. Changing a decision requires a new ADR that supersedes the old one.
