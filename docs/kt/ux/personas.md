# Personas

Depth behind the overview user table. The MVP pilot is one invited organization; primary industry for the pilot is chosen when the pilot org is named (not an open architecture question).

## Innovation lead

| Field | Value |
|---|---|
| Role | viewer |
| Goal | Choose three developments to explore this quarter for their industry |
| Frequency | Weekly shortlist review; monthly deep dive |
| Constraints | No research background required; needs explainable scores and sources |
| Done when | Exported briefs for a shortlist and a decision meeting agenda |
| Not done when | Only a long unranked paper list |

## Consultant

| Field | Value |
|---|---|
| Role | viewer |
| Goal | Bring evidence-based software ideas to a client workshop |
| Frequency | Per engagement |
| Constraints | Must cite sources and label estimates; client may be outside the four industries' focus areas |
| Done when | Brief plus competitor and market context for 5–10 opportunities |
| Not done when | Claims without evidence or estimate labels |

## Venture builder

| Field | Value |
|---|---|
| Role | viewer or analyst |
| Goal | Find concepts worth a validation sprint |
| Frequency | Continuous scanning during intake |
| Constraints | Needs next steps and business case, not only a score |
| Done when | Concept + next steps + status `pursued` or `parked` (analyst) |
| Not done when | Score without a concept or next steps |

## Domain reviewer

| Field | Value |
|---|---|
| Role | analyst |
| Goal | Judge whether platform output is right for an industry |
| Frequency | Golden-set labeling sessions; ongoing score reviews |
| Constraints | Needs evidence quotes and related publications |
| Done when | Reviews recorded; disagreements exported to calibration |
| Not done when | No way to dispute or to see why a score was derived |

## Platform operator

| Field | Value |
|---|---|
| Role | admin |
| Goal | Keep the pilot running within budget and invite the right people |
| Frequency | Daily glance at pipeline and cost; as-needed invites |
| Constraints | Must recover failed candidates without a deploy |
| Done when | Invitations, hides, reruns, and budget view work without engineering |
| Not done when | Dead letters or failed runs with no admin path |
