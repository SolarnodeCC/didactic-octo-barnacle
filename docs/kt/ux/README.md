# UX specification

Written screen specifications for the dashboard, with low-fidelity wireframes. The requirements in [dashboard](../requirements/dashboard.md), [accounts](../requirements/accounts.md), and [admin](../requirements/admin.md) say what each screen must do; these documents say where it lives, who sees it, and what it shows in every state.

- [Screens](screens.md): the screen inventory, navigation, and role access.
- [Journeys](journeys.md): the user journeys and how personas map to roles.
- [Screen states](states.md): empty, loading, error, and validation states shared by the screens.
- [Wireframes](wireframes.md): low-fidelity layouts of the main screens.
